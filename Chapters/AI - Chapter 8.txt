With an evaluation function that assigns the values [1, 2, 3, 4] to the leaves, move a1 is best; 
with values [1, 20, 30, 400], move a2 is best. Hence, the program behaves totally differently if 
we make a change in the scale of some evaluation values! It turns out that to avoid this 
sensitivity, the evaluation function must be a positive linear transformation of the probability 
of winning from a position (or, more generally, of the expected utility of the position).
