2/8. Formal definitions
11◼Begin with a set Ω called the sample space (=universe)
❑An element ω is a sample = a possible world = an atomic event
❑e.g., A domain with a single die: Ω = 6 possible rolls
◼A probability space (or model) is a sample space with an  
assignment P(ω) for every ω ∈ Ωs.t.
❑0 ≤ P(ω) ≤ 1, ∑ ω P(ω) = 1
❑e.g., for an unbiased die roll, P(Roll=1)= … =P(Roll=6)=1/6,  
P(Roll=1) + … + P(Roll=6) = 1
◼An (possibly non -atomic) event A is any subset of Ω
❑P(A) = ∑{ω ∈ A}P(ω)
❑e.g., A:Roll<4, P(A) = P(Roll=1) + P(Roll=2) + P(Roll=3) = 3*1/6
=1/2

Marginalization revisited
32◼In general, if you have P(X,Y,Z) and you want P(X,Y)
❑Sum P(X,Y,Z) over all possible values for Z
❑P(X,Y) = zP(X,Y,Z=z)
= P(X,Y,Z=z1) + … + P(X,Y,Z=zn)
◼Similarly, if you have P(X,Y|Z) and you want P(X|Z)
❑Sum P(X,Y|Z) over all possible values for Y
❑P(X|Z) = yP(X,Y|Z)
= P(X,Y=y1|Z) + … + P(X,Y=yn|Z)
◼Eliminating a variable by summing over all values of that  
variable is called “marginalizing out.”
