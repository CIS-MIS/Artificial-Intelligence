18Properties of task environments
Deterministic  (vs. stochastic) : The next  state  of the environment  is completely  
determined  by the current  state  and the action  executed  by the agent . (If the 
environment  is deterministic  except  for the actions  of other  agents,  then  the

Episodic vs. Sequential
Episodic: current action affects only the current episode
Sequential: future episodes as well (e.g., chess, or taxi driving)
Static vs. Dynamic
Static: time halts while agent makes a decision
Turn-based games (e.g., Monopoly)
Dynamic: world changes on while agent decides

an effect on performance score
