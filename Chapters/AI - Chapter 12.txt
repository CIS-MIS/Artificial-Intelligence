Propositionalization
8◼We can “propositionalize” the FOL sentences by  
instantiation, and use propositional inference rules
◼A problem: functions can generate an infinite number of  
sentences
❑Duck(Howard) ⇒Bird(Howard)
❑Duck(FatherOf(Howard)) ⇒Bird(FatherOf(Howard))
❑Duck(FatherOf(FatherOf(Howard))) ⇒Bird(FatherOf(FatherOf(Howard)))

prove entailments
❑When the query is not entailed, nesting doesn’t stop….
◼The question of entailment for first -order logic is

Reduction continued
10•Every FOL KB can be propositionalized so as to preserve 
entailment
–A ground sentence is entailed by new KB iff entailed by original KB
•Idea for doing inference in FOL:
–propositionalize KB and query
–apply resolution -based inference
– return result
•Problem: with function symbols, there are infinitely many 
ground terms,
–e.g., Father (Father (Father (John))), etc
Reduction continued
11Theorem: Herbrand  (1930). If a sentence α is entailed by a FOL 
KB, it is entailed by a finite subset of the propositionalized KB
Idea: For n = 0 to ∞ do
    create a propositional KB by instantiating with depth n terms
    see if α is entailed by this KB
Problem: works if α is entailed, loops if α is not entailed.
              → The problem of semi -decidable: algorithms exist
                  to prove entailment, but no algorithm
                  exists to prove non -entailment for every
                   non-entailed sentence.

Unification
14◼Unification is the process of finding substitutions  
to make two sentences the same ondemand
❑If SUBST({x/z},p) = SUBST({y/z},q), then
❑UNIFY(p,q) = {x/z, y/z} : common constant/variable  
that makes two sentences the same after substitution
◼Example:
❑UNIFY(Duck(y),Duck(Howard) )={y/Howard}
❑UNIFY(Duck(Donald),Duck(Howard)) =FAIL
