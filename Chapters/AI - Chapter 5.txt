6◼A heuristic function h(n)

such that h(n)≥0, and h(n)=0 only if n is a goal state
❑means: estimated lowest cost from the state at node n

25◼A* search is complete and optimal if
❑h(n) is admissible (for tree search)
❑h(n) is consistent (for graph search)
◼Def: h(n) admissible if
❑h(n) always underestimates the cost to the goal
❑i.e.h(n) ≤ h*(n) for all n, where h*(n) is the (true) least cost to the
Goal
•An admissible heuristic never overestimates  the cost to reach the 
goal, i.e., it is optimistic
◼Def: h(n) consistent if
❑h(n) ≤ c(n,a,n’) + h(n’), where n’ is a child of n
❑~ triangle inequality
◼If h(n) consistent then h(n)admissible

Proof of the optimality of A* -1
28◼Let’s prove that A* is optimal if h(n) is consistent  
for graph search
◼Lemma 1: if h(n) is consistent, then f(n) along  
any path is nondecreasing
◼Proof:
❑Let n’ is a child of n, then g(n’) = g(n) + c(n,a,n’) for  
some action a, and wehave
❑f(n’) = g(n’) + h(n’) = g(n) + c(n,a,n’) +h(n’)
≥ g(n) + h(n) =f(n)
Proof of the optimality of A* -2
29◼Whenever a node is selected for expansion, the  
optimal path to that node has been found by A*
◼Proof:
❑Suppose the lemma were not true, i.e., then there is a  
frontier node n’ on the optimal path from the root to n
❑By lemma 1, f(n’)<f(n) , and n’ must have been  
selected before n
→Contradiction!
◼As a result, if a goal is found, then the current  
path to the goal is an optimal one
